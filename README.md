# Workforce Upskilling Program — shared hub

Shared references for the Workforce Upskilling Program (WUP).

## Registrar credit registry

Authoritative continuing-education-unit values are maintained by the
Registrar's office in `registry/ceu_registry.csv`.

- Keys use the registrar module code without any LMS section suffix.
- Update cadence: quarterly, before each programme intake.

## Companion resource kits

Learner-facing resource kits live under `resources/`. Each kit keeps
its own README which states whether the kit has been released.
